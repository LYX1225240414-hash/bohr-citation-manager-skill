# 格式映射、去重判据与核验要点

## GB/T 7714—2015 常用字段
- 期刊 `[J]`：作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
- 会议 `[C]`：作者. 题名[C]//会议名. 出版地: 出版者, 年: 页码.
- 学位论文 `[D]`：作者. 题名[D]. 保存地: 保存单位, 年.
- 预印本 `[EB/OL]`：作者. 题名[EB/OL]. (发布日期)[引用日期]. URL/DOI.
- 中英文混排：中文文献保留中文标点，英文文献用英文标点；卷期页与 DOI 不得丢失。

## APA 7 常用字段
- 期刊：Author, A. A., & Author, B. B. (Year). Title of article. *Journal Title*, *volume*(issue), pages. https://doi.org/xxx
- 会议/预印本：保留出版者或平台名与 DOI；无 DOI 时写稳定 URL。
- 作者超过 20 人时按规范省略并标明；不得凭空补作者。

## BibTeX / RIS / EndNote / CNKI → 目标格式的字段映射
| 源字段 | 目标字段 | 注意 |
|---|---|---|
| `doi` / `DO` | `doi` | 统一小写前缀 `https://doi.org/` 或裸 DOI，按目标规范 |
| `title` / `TI` / `题名` | `title` | 保留大小写原样；中英文题名并存时合并为一条并记依据 |
| `author` / `AU` / `作者` | `authors` | 姓名顺序按目标规范重排，不增减作者 |
| `journal` / `JF` / `刊名` | `venue` | 会议名与期刊名不得混填 |
| `volume` / `issue` / `pages` / `VL` / `IS` / `SP` | 卷/期/页 | 缺项填“原文未述” |
| `type` / `TY` / `文献类型` | `type` | 缺失时按来源判断并在 uncertainties 标注 |

## 去重判据（由强到弱）
1. DOI 相同 → 直接合并，记录两条来源与合并依据。
2. 题名归一化相同 + 作者首人相同 → 合并；年份/venue 冲突写入 uncertainties。
3. 预印本与正式版题名相近 + 作者与年份一致 → 可合并为正式版，`after` 保留 DOI 版本说明。
4. 仅同名作者或仅相似主题 → 不合并，分列并写明差异。

## 来源核验
- 有 DOI：核验格式与目标页是否指向同一题名/作者；不符则 `verified: false` 并写入 uncertainties。
- 无 DOI：仅能按要求元数据字段核对，标 `verified: unchecked`，不得写“已核实”。
- 正文论断—文献主题匹配：逐句写出 `match_basis`（文献的方法/数据/结论如何支撑该论断），不以“相关”二字替代。
